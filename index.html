Abstract

Language-model agents increasingly rely on harnesses that manage bounded context, persistent memory, tools, verification, and repeated execution, but existing notions of model capability do not quantify the computational resources these mechanisms consume. We develop a theory of these costs through the Language Model Agent Machine (LAM), a resource-bounded model that fixes the underlying semantic model while explicitly charging harness-level resources. Our theory yields four classes of results. Communication: LAM executions correspond instancewise to red–blue pebbling, transferring classical I/O lower bounds to context–memory traffic. Access: memory interface changes asymptotic cost, including a Θ(n)\Theta(n)Θ(n) separation between random and non-speculative sequential access on pointer chasing and an exact single-stack FIFO frontier. Recomputation: bit-reversal DAGs require Θ(n2/(C+S)+n)\Theta(n^2/(C+S)+n)Θ(n2/(C+S)+n) model calls with context capacity CCC and persistent-memory capacity SSS, quantifying when stored intermediate state avoids repeated semantic computation. Reliability: we derive tight stage-local sampling bounds, exact imperfect-verification costs, and a Young–Daly-type checkpoint law with a closed-form optimal verification interval. Controlled and frontier-model experiments test these theoretical predictions, matching prescribed call counts and checkpoint optima and validating the resulting strategy choices. Together, these results provide a resource theory for the computational cost of language-model agent harnesses. Project page: https://anoynomous1776research.github.io/LAM-ICLR2027/.

The Language Model Agent Machine

Language models are increasingly deployed as components of persistent agentic systems: a harness calls the model repeatedly, keeps state in external memory, invokes tools, and verifies or revises intermediate results over many rounds. Theory has kept pace with the power of such systems, but universality does not distinguish ten model calls from ten million, quantify the state that must cross between a large store and a small context window, or say whether a thousand-step computation stays correct when transitions are imperfect. Universality is in fact cheap in our model, costing O(1)O(1)O(1) model calls and block movements per simulated Turing-machine step at a constant number of context blocks (Proposition 8, appendix). This paper therefore asks a different question: holding the semantic oracle fixed, what does the harness around it spend?

Machine model. The LAM models harness-level execution, the prompt construction, state, memory, tools and verification around a model, not the model’s internal computation. Fix an input size nnn and a finite alphabet Σ\SigmaΣ; a semantic block is a fixed-width unit of task-relevant information, an element of Bn=Σb(n)\mathcal{B}_n=\Sigma^{b(n)}Bn​=Σb(n). A LAM is a tuple

Λ=(L, ctrl, X, M, Otool, Over),\Lambda=(L,\ \mathrm{ctrl},\ X,\ M,\ O_{\mathrm{tool}},\ O_{\mathrm{ver}}),Λ=(L, ctrl, X, M, Otool​, Over​),

where LLL is the model interface, ctrl\mathrm{ctrl}ctrl the harness controller, XXX the active context (at most CCC blocks simultaneously available to the next model call), MMM the persistent memory (at most SSS blocks across calls, outside XXX; a stored block must be retrieved into XXX before it can participate in a call), and OtoolO_{\mathrm{tool}}Otool​ and OverO_{\mathrm{ver}}Over​ the tool and verifier interfaces. A call to LLL consumes blocks in XXX and inserts its output as a new block of XXX, so a call takes at most C−1C-1C−1 argument blocks. A tool call performs an explicitly charged external operation and returns a semantic block; a verifier call returns a tag only (accept/reject) and inserts no block. No interface sees the input, MMM, or a block not passed to it. The controller is a finite control with tag and address registers that sees block contents only through returned tags and decoded addresses.

Value provenance. To separate harness orchestration from semantic computation, every semantic block must originate from the input, a fixed constant, or the output of a model, tool, or verifier call. The controller may route, copy, store, retrieve, and schedule existing blocks, but it cannot generate new task-relevant semantic content on its own. This restriction is load-bearing: without it the lower bounds collapse, so production parsing, ranking, arithmetic or code execution must be charged as explicit computation or lies outside the lower-bound model.

Two classical theories anticipate two of these resources: the red–blue pebble game of Hong and Kung lower-bounds the traffic between a small fast memory and a large slow one, and reliable computation from unreliable components anticipates an agent whose transitions are expensive and imperfect. An agent exhibits both at once, and the LAM recovers and sharpens both classical theories: Theorem 1 transfers every Hong–Kung I/O lower bound instancewise to context–memory traffic, and Theorem 6 recovers the Young–Daly checkpoint law with its exact cost, a closed-form optimum and the class of rollback policies in which it holds.

Results

The results isolate four harness costs: communication, access, recomputation and reliability. Each result states a design Problem, its Assumptions and its Conclusion. Comparisons hold the semantic oracle fixed; only the harness changes.

Numbering follows the current manuscript. Theorems 1 to 6 appear in the main text; the other results appear in the appendices.

Common definitions

Value provenance. Every semantic block originates from the input, a fixed constant, or the output of a model, tool or verifier call. The controller may route, copy, store, retrieve and schedule blocks, but never manufacture one. Under this axiom, the lower bounds concern the harness rather than the model.

Base evaluation (Definition 1). A deterministic run evaluates a computation DAG GGG and nothing else:

  • Every source block is held in memory MMM from the start; the context XXX starts empty.
  • Every value-producing call is an LLL-call realising one vertex on the blocks of its predecessors. There are no auxiliary value-producing calls.
  • Blocks are identified by provenance: equal contents do not make one block a substitute for another.
  • The run ends with a block for each designated sink resident in XXX or held in MMM.

An input-delivered base evaluation instead receives each source exactly once through the input port.

Theorem 1 (red–blue pebbling correspondence).

For base evaluations, classical I/O bounds become context–memory traffic bounds.

Design rules

  • Send a step its dependencies, not the history. On chains whose steps read O(1)O(1)O(1) earlier blocks, dependency-only prompting uses linear rather than quadratic input traffic (Proposition 12). The reported frontier-model factors are 7.1×7.1\times7.1× and 11×11\times11×.
  • Reach state by random access. Pointer chasing has a Θ(n)\Theta(n)Θ(n) memory-operation gap over non-speculative sequential access (Theorem 2). The broader read-only result gives an Ω(n)\Omega(n)Ω(n) lower bound on total sequential head movement even with speculation (Proposition 14).
  • Persist reusable blocks. Bit-reversal reuse gives a Θ(n/C)\Theta(n/C)Θ(n/C) model-call gap in the stated sublinear-context regime (Theorem 3). Memory saves no model calls when the live state already fits in context (regime i).
  • Buy feedback, then choose the checkpoint interval. On the stage-local hard family, feedback removes the log⁡(n/δ)\log(n/\delta)log(n/δ) sampling factor (Theorems 4 and 23). With an imperfect verifier, repeated checks improve accepted-error odds only for 0<pa<1−pr0< p_a<1-p_r0<pa​<1−pr​; if pa=0p_a=0pa​=0, one check suffices (Theorem 5). Use k⋆k^\stark⋆ to choose an interval for expensive checks (Theorem 6), or combine local checks with rollback (Proposition 30). The frontier-model tournament selected its winning policy from these formulas before the run and confirmed the winner afterwards.

Conclusion

Fixing the semantic oracle and charging harness resources makes agent designs comparable by cost at a stated reliability rather than by universality alone. With a frontier model as oracle on vertex-wise chain evaluation, dependency-only prompting used 7.1×7.1\times7.1× and 11×11\times11× fewer logical input tokens than full-history replay; the oracle made no calibration error under the corrected routing, and the reliability laws are matched by controlled simulation, the exact checkpoint-cost curve to within 1.3%1.3\%1.3%. Each remedy pays conditionally: persistent memory saves calls until C+SC+SC+S reaches nnn (Theorem 3), repeated checks help while pa<1−prp_a<1-p_rpa​<1−pr​, false rejects costing (n/δ)α(n/\delta)^{\alpha}(n/δ)α (Theorem 5 and the appendix Corollary 21), and rollback at k⋆∼cv/εk^\star\sim\sqrt{c_v/\varepsilon}k⋆∼cv​/ε​ for small ε\varepsilonε, cvεc_v\varepsiloncv​ε (Theorem 6).
