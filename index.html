Language Model Agent Machines (LAM)

Harnessing LLMs as Agents: What Does It Cost?

A resource-bounded model of a bounded-context language model together with its harness.

Universality is too coarse a description of a deployed agent. It says nothing about how many model calls a computation needs, how much state must cross the boundary between a small context and a large store, or whether a thousand-step trajectory stays correct. The LAM makes active context, persistent memory, the memory-access interface, tools and verification explicit resources and, holding the model fixed, charges the harness for what it spends.

The framework

One machine, six components, five charged counters

A LAM models harness-level execution rather than the model's internal computation. A semantic block is a fixed-width unit of task-relevant information, Bn = Σb(n); the accounting separates model calls, model-input and model-output symbols, context–memory block transfers, and sequential head movements. Tool calls, verifier calls and external observations of input blocks are counted separately where applicable.

Controller ctrldetermines the sequence of harness operations: which blocks occupy X, which calls happen when, and every read and write to M. Under value provenance it may route, copy, store, retrieve and schedule existing blocks only.

Persistent memory M

Capacity S blocks. Random access reads a block at a given address; a sequential interface stores blocks in an ordered stream and reaches them with a movable head; a stack pushes and pops.

blue pebble = a stored copy of the block

Qblk load / store, one block each Qmove unit head moves (sequential only)

Active context X

Capacity C blocks, all simultaneously available to the next model call. Includes the controller's own semantic working storage: there is no uncharged fast memory beside it.

red pebble = a block currently in context

Tin ≤ C−1 argument blocks Tout one new block, inserted before any eviction

Model interface L

The fixed semantic oracle. Each call is counted in N; its input and output symbols in Tin and Tout. The model is held fixed throughout: every comparison isolates the harness, not model power.

Tool interface Otool

An explicitly charged external operation on selected semantic state, returning a semantic block (counted in Ntool). Parsing, retrieval scoring or code execution that creates values must be modelled here and charged; it is not free controller work.

Verifier interface Over

Checks a semantic block and returns accept or reject (counted in Nver, weighted by cv relative to one model call, so Cost = Nmodel + cvNver).

Red–blue reading (Hong–Kung): a load puts a red pebble on a blue-pebbled vertex, a store puts a blue pebble on a red-pebbled one, a vertex may be computed (given a red pebble) when all predecessors are red, and either pebble may be deleted. Red pebbles ≤ C, blue pebbles ≤ S, and each load or store adds one to Qblk. The stored copy stays in place on a load, so a block already held in memory is never stored twice.

Model calls, memory-interface operations and input length are different costs; the results below keep them apart.

The value-provenance restriction load-bearing

Every semantic block must originate from the input, a fixed constant, or the output of a model, tool or verifier call. The controller may route, copy, store, retrieve and schedule existing blocks, but cannot generate new task-relevant content on its own.

Why it matters: if the controller could compute an arbitrary polynomial-time function of the blocks it reads, it could emit the matrix-multiplication answer after reading the input once, at N = 0 model calls and Qblk = Θ(n²) transfers against a pebbling bound of Ω(n³/√C). The lower-bound direction of the pebbling correspondence, and everything that reduces to it, collapses. Production parsing, ranking, deterministic arithmetic or code execution must therefore be charged as explicit computation or lies outside the lower-bound model.

Universality is cheap here

A one-tape Turing machine running in time t and space s is simulated by a LAM with random-access memory of size O(s), C = O(1) blocks and one deterministic oracle, at N = O(t) calls, Qblk = O(t), Qmove = 0 and Tin = O(t·b). What separates agent designs is the resources universality ignores.

Communication

Replay or persist? How much state must cross the context–memory boundary, and how much of it re-enters each model call.

Theorem 1

Red–blue pebbling correspondence

(i) Any execution with capacities (C, S) induces a valid red–blue pebbling with at most C red and S blue pebbles and at most Qblk load and store moves. (ii) Any such pebbling induces a LAM execution with capacities (C, S) and at most the same transfer count. For fixed capacities and matching initial and terminal conventions,
min Qblk(G; C, S) = IOC,S(G)
where IOC,S is the minimum transfer count with at most C red and S blue pebbles. Classical I/O lower bounds therefore transfer to these executions.
Class

A fixed L-realisable computation DAG G, compared with the red–blue pebble game at the same capacities. No distributional assumption over tasks.

Needs
  • Source blocks held in M; G evaluated vertex by vertex.
  • No auxiliary value-producing tool or verifier calls (otherwise include them as vertices of an augmented DAG G+ and argue there).
  • Value provenance; all semantic working storage, including controller block registers, counted inside C.
  • Maximum in-degree d needs C ≥ d + 1 so arguments and result co-reside; recomputation allowed.
Not claimed

Direction (ii) compiles one fixed graph and schedule into a controller; it is not a uniform algorithm for a task family. Without value provenance the lower-bound direction collapses.

Corollary 2

Communication bounds for two DAGs

grid: min Qblk = Θ(n²/C)  for 3 ≤ C ≤ c·n and sufficient persistent memory
bilinear matrix multiplication: Qblk = Ω(n³/√C)
Even for a fixed computation DAG, limited active context forces a LAM to transfer provably many semantic blocks. Both statements are under the pebbling-correspondence hypotheses; the grid's matching upper bound is a uniform tiled schedule driven by public structural counters (appendix), not an appeal to direction (ii) above.
Class

The n × n grid computation DAG and the bilinear n × n matrix-multiplication DAG, under the hypotheses of Theorem 1.

Needs
  • Grid lower bound: 3 ≤ C ≤ c·n for a small absolute constant c; sufficient persistent memory (S ≥ |V| suffices).
  • The grid Θ(n²/C) conclusion is stated here only in the range of the corollary.
  • Both DAGs have in-degree at most two, so the insertion convention requires only C ≥ 3.
Not claimed

These are block-transfer bounds, not model-call bounds. No transfer claim is made for adaptive comparison sorting, whose external-memory bound uses a different model.

Proposition 3

Sequential input traffic: replay versus dependencies

On an n-step sequential computation whose steps each produce a Θ(b) block, giving call i every earlier block costs Θ(ib) input, hence
Tin = Θ(n²b)  (replay)    Tin = Θ(nb)  (dependencies only)
Dependency-only prompting has linear input traffic under the stated bounded-dependency assumption. Relative to this protocol, full-history replay uses a factor Θ(n) more input symbols.
Class

Two named protocols on a chain: full-history replay versus supplying only the blocks a step reads.

Needs
  • Replay must hold the whole transcript, so it requires C ≥ n.
  • The linear bound requires each step to depend on only O(1) earlier blocks, and only those to be supplied.
  • This proposition compares the two named prompting protocols; it does not establish optimality over arbitrary harnesses or batched oracle calls. (The appendix adds a floor of N ≥ n calls and Tin ≥ nb for non-degenerate steps, valid within the one-output-block-per-call convention and value provenance.)
Not claimed

This compares particular protocols; it does not assert that every execution without external memory has quadratic input traffic. Where the whole task fits in one call, one-call execution is cheaper still: avoiding replay is not a universal advantage.

Access

Which interface? With the oracle fixed, how an agent reaches external state changes its asymptotic cost, and no interface evades what the task itself demands.

Theorem 4

Random versus sequential access on pointer chasing

A random-access LAM follows k pointers with k model calls, Qblk = Θ(k), Qmove = 0 and C = O(1). Every deterministic, always-correct, non-speculative sequential LAM satisfies
𝔼π[Qmove] = Ω(kn),  hence  𝔼π[Qmem] = Ω(kn)
Both systems make the same k semantic transitions and retrieve the same k entries; the sequential interface can incur an additional Θ(n) access cost per step. The lower bound is in expectation over a uniformly random permutation: it is not an Ω(n) charge on every hop or every input. A straightforward demand-driven sequential implementation has matching O(kn) total head movement.
Class

Pointer chasing over a table of n entries holding a permutation π of [n]; random access versus the non-speculative sequential class, same oracle. Expectation over π uniformly random.

Needs
  • 2 ≤ k ≤ n/4; one semantic block holds an index in [n].
  • The sequential execution is deterministic, always correct, and non-speculative: it may read an entry only after its address has been revealed by the preceding step. Preprocessing and prefetching of unrevealed entries are excluded.
Not claimed

The speculative case is open: a one-time Ω(n) scan does not imply Ω(kn), and the paper declines to infer it. The bound is on head movement, not on symbols physically transferred (it is not an Ω(knb) traffic bound).

Theorem 5

Query bandwidth

Every deterministic LAM computing f has, on some input,
N(C−1) + Qobs ≥ D(f)
and every randomized LAM with error at most 1/3 on each input has maxx 𝔼x[N(C−1) + Qobs] ≥ R1/3(f). For the selector f(s, d1, …, dm) = ds, D(f) = 2; for parity of m blocks, D(f) = m.
Class

Any LAM computing a task f : Bnm → Bn, under any memory interface. D(f) is deterministic worst-case block-query complexity; R1/3(f) the randomized worst-input expected count.

Needs
  • Value provenance and C ≥ 2.
  • Qobs counts every observation of an input block outside model-call arguments, by the controller, a tool or a verifier; each call exposes at most C − 1 argument blocks.
Not claimed

It bounds the information the task forces the agent to observe, not the cost of reaching a block (that is Theorem 4). Global relevance is the wrong quantity for adaptive access: all m + 1 selector inputs are relevant, yet two observations suffice.

Theorem 18 appendix

A single stack needs linear context for FIFO

Random access solves FIFOn with C = 1 and Q = 2n. With one stack, the requirement depends on how the write phase is organised:
buffered: n ≤ 3C′  (so C′ ≥ n/3; C = ⌈(n+1)/2⌉ suffices)
streaming: (C−1)·log₂|B| + h ≥ (n−1)·log₂|B|  (so h = O(1) forces C ≥ n − O(1))
Class

FIFOn: a write phase receives arbitrary blocks x1, …, xn in order, a read phase must return them unchanged in that order. One stack plus C context blocks; h bounds the bits of content-dependent state outside both; C′ = C + ⌊h / log₂|B|⌋.

Needs
  • Correctness on every input; blocks opaque under value provenance.
  • Buffered write phase: arrivals may be held in context before pushing. Streaming write phase: each block is pushed as it arrives.
  • Public structural counters are input-independent and cannot encode the suffix.
Not claimed

One stack, not two. In the buffered case only the linear order is claimed; the tight constant lies between 1/3 and 1/2. The hidden-state budget h is part of the restriction: at sublinear context, evading the stated bound requires a linear-order amount of additional content-dependent storage, which must not be treated as free controller state.

Recomputation

Persist or regenerate? Persistence saves model calls, not only traffic, when intermediate results are reused after they have left context.

Theorem 6

Persistence versus recomputation on bit-reversal DAGs

NRAM = Θ(n), Qblk = O(n)   versus   Nno memory = Θ(n²/C + n)
With persistent memory each intermediate block is computed once, stored, and retrieved. Without it, limited context cannot retain blocks until their future uses, so discarded blocks are regenerated. The model-call overhead is a factor Θ(n/C) when C = o(n).
Class

The bit-reversal DAG Δnrev: two length-n chains u, w with edges ui → wrev(i). A LAM with random-access persistent memory versus one with no persistent memory (S = 0), same oracle.

Needs
  • n a power of two; the DAG L-realisable.
  • Evaluated vertex by vertex with no auxiliary value-producing calls; the unique source block kept resident in active context.
  • 4 ≤ C ≤ n; the ratio Θ(n/C) is stated for C = o(n), i.e. C/n → 0.
Not claimed

A polynomial call–space trade-off, not an exponential one. It instantiates the Lengauer–Tarjan bit-reversal bound for this reuse pattern; it is not a statement about arbitrary DAGs.

Reliability checked in simulation only

Sample, verify or checkpoint? A chain of n dependent transitions; given a correct state, a call returns the intended successor with probability 1 − ε, and an undetected error propagates. Errors are absorbing throughout. The frontier-model runs produced no oracle error in calibration, so none of these results is tested with that model; a small exploratory diagnostic probes the assumptions only.

Proposition 20 appendix

Unamplified success and an idealised restart

Pr[single pass correct] = (1−ε)n,   𝔼[N] = n(1−ε)−n under restart-until-success
A long trajectory without correction is almost surely wrong somewhere.
Class

Independent per-step success 1 − ε; the restart figure is an idealised comparison point, not a policy.

Needs
  • The restart count assumes a perfect, cost-free end-of-run correctness detector.
Not claimed

Without such feedback the restart policy cannot be implemented; the executable no-feedback baseline is Theorem 8.

Theorem 7

Sampling amplification (upper bound)

A plurality vote over m = O(γ−2 log(An/δ)) independent samples per transition gives overall failure at most δ using
N = O(nγ−2 log(An/δ)) model calls
Class

Stage-local plurality voting on a chain of n transitions.

Needs
  • Repeated calls at the same correct state are independent.
  • At most A incorrect alternatives have nonzero probability, each with probability at most pc − γ, where pc is the correct block's probability and γ > 0.
Not claimed

An upper bound only, with a constant that depends on A; the logarithmic factor is shown necessary only on the family of Theorem 8.

Theorem 8

Stage-local sampling lower bound

There is a depth-n binary-tree family of γ-separated transition distributions on which every stage-local sampling-only strategy achieving failure at most δ satisfies
𝔼[N] ≥ (n/4γ²)·log(n/8δ) = Ω(nγ−2 log(n/δ))
Together with Theorem 7 this is the optimal order, Θ(nγ−2 log(n/δ)), for that family and class.
Class

Stage-local sampling-only strategies: any adaptive number of samples per step, arbitrary aggregation within a stage, but no correctness signal and no revision of a committed transition after moving on. Proved on one specific hard family.

Needs
  • γ ≤ 1/2 and δ ≤ 1/4.
  • Off-path states have the same local sampling law as correct-path states, so an error does not reveal itself through later outputs (no lookahead signal).
  • Stopping almost surely finite with finite expected sample counts.
Not claimed

The bound is against the no-feedback class, not arbitrary interactive reliability mechanisms: a strategy that receives feedback (Theorem 9) escapes it.

Theorem 9

Perfect local verification

Resampling a transition until a perfect verifier accepts achieves zero failure with
𝔼[Nmodel] = 𝔼[Nver] = n/(1−ε),   𝔼[Cost] = n(1+cv)/(1−ε)
which is Θ(n) for fixed ε < 1 and cv. On the hard family of Theorem 8 this removes the Θ(log(n/δ)) overhead of stage-local sampling for constant γ and cv.
Class

Verify-every-transition with a perfect local verifier, weighted cost Cost = Nmodel + cvNver.

Needs
  • A perfect local verifier (no false accepts or rejects).
  • Independent attempts, each succeeding with probability 1 − ε > 0.
Not claimed

The gain comes from feedback, not from more sampling. The weighted-cost ratio against sampling is Θ(γ−2 log(n/δ)/(1 + cv)) and exceeds one only while cv = O(γ−2 log(n/δ)); this necessary order condition is not a sufficient cost comparison at the crossover. A perfect verifier is a strong assumption, relaxed next.

Theorem 10

Imperfect local verification, characterised exactly

With at = (1−ε)(1−pr)t, bt = ε pat, st = at + bt: an accepted candidate is wrong with probability qt = bt/st, attempts per accepted transition are 1/st, and
𝔼[Nmodel] = n/st,   𝔼[Nver] = nt/st,   𝔼[Cost] = n(1+tcv)/st,   Pr[chain failure] ≤ nqt
The accepted-error odds decrease with t only when pa < 1 − pr.
Class

A verifier with false-accept probability pa and false-reject probability pr, applied t times per candidate; a candidate is accepted only if all t checks accept.

Needs
  • pr < 1; candidate attempts and conditional verifier decisions independent.
  • Every attempt pays for all t checks; the acceptance rate is the same at every visited state, including after an earlier accepted error.
Not claimed

More checking is not free: false rejects suppress the correct-acceptance term (1−ε)(1−pr)t, and increasing t can lower the overall acceptance probability st and substantially increase model calls. Correlated errors are outside this statement.

Theorem 11

Checkpoint law with rollback

Verifying every k transitions and re-executing the whole rejected segment has expected weighted cost
T(k) = (n/k)(k + cv)(1−ε)−k
With β = −log(1−ε), the positive-real minimiser is
k⋆ = ½(√(cv² + 4cv/β) − cv)
so k⋆ = √(cv/β)(1 + O(√(cvβ))) as cvβ → 0, and k⋆ ~ √(cv/ε) if additionally ε → 0.
Class

The regular checkpoint-and-rollback policy with a perfect segment verifier; a Young–Daly-type law (the classical optimum differs by √2 because a rejected segment is re-executed in full).

Needs
  • Independent transition errors with probability ε, 0 < ε < 1; perfect segment verifier of cost cv > 0.
  • The displayed formula assumes k | n. Otherwise write n = qk + r, 0 ≤ r < k; the exact cost is q(k + cv)(1−ε)−k + 𝟙{r > 0}·(r + cv)(1−ε)−r.
  • For finite horizons, minimise the exact expression over admissible integer k ∈ [1, n].
Not claimed

The leading-order √(cv/ε) is accurate only when both ε ≪ 1 and cvε ≪ 1; in simulation it is off by a factor of two at ε = 0.1, cv = 16. Use the closed form.

Reading the four results together

A regime map, with explicit quantifiers

Appendix theorems combine the results into witness regimes where a harness mechanism pays for itself and a counter-regime where it does not. All comparisons use the same fixed semantic oracle and each keeps its own restrictions.

(i) Fits in contextno asymptotic model-call gain from memory

Let m be the number of internal value-producing vertices of a fixed L-realisable DAG. Under vertex-by-vertex evaluation by model calls, with no auxiliary value-producing calls, a memoryless evaluator and a memory-equipped one both use Θ(m) model calls if a deterministic non-degenerate no-eviction schedule of live width at most C fits in context: each such vertex requires one oracle output under value provenance.

Class: the same fixed DAG and oracle, with all semantic working storage and argument/result co-residence counted in C. This is a model-call comparison, not equality of all resource costs.

(ii) InterfaceΘ(n) gap or infeasibility

On pointer chasing, random access versus an always-correct non-speculative sequential interface has a worst-case memory-operation gap of Θ(n). On FIFOn, random access works at constant context whereas one stack with h = 0 needs C ≥ n/3.

Class: Theorems 4 and 18, with their hypotheses.

(iii) PersistenceΘ(n/C) call gap

On Δnrev under vertex-wise evaluation, random-access memory versus S = 0 has a model-call gap of Θ(n/C).

Class: Theorem 6, for C = o(n).

(iv) Feedbacklogarithmic gap

On the hard family of Theorem 8, the weighted cost of stage-local sampling divided by that of verifying every transition is Θ(γ−2 log(n/δ)/(1 + cv)), hence Θ(log(n/δ)) for constant γ, cv.

Class: a ratio between two named policies, not an advantage over all strategies. It exceeds one only while cv = O(γ−2 log(n/δ)), a necessary order condition that is not a sufficient cost comparison at the crossover, and a class that may ignore its verifier never does worse than sampling alone.

Joint accountingTheorem 23, checkpoint decomposition

Assume independent transition errors with probability 0 < ε < 1, independent fresh retry attempts, and a perfect segment verifier of cost cv > 0 that detects errors only at segment boundaries. Write β = −log(1−ε), B = Σi bi and κ ≥ 1. For a fixed no-recomputation schedule partitioned into segments with ℓi calls and base cost bi, detecting errors only with a perfect verifier of cost cv at segment boundaries and rolling back the whole segment gives exactly 𝔼[Cost] = Σi(bi + cv)(1−ε)−ℓi, provided a rejected segment restarts from its entry frontier at no charge beyond bi. Every regular partition with ℓi ≤ bi ≤ κℓi costs at least B(1 + 2√(cvβ/κ)); if cvβ = O(1) and independently verifiable segments of length Θ(√(cv/β)) exist, the best regular partition costs Θ(B(1 + √(cvβ))).

Class: an optimum only within the checkpoint-and-rollback class, with a rejected segment restartable from its entry frontier at no charge beyond bi. The unrestricted harness optimum is lower-bounded only by its noiseless optimum and may sample, encode redundantly or use another verifier.

These are sufficient witness and counter-regimes, not necessary-and-sufficient conditions for arbitrary tasks. Working-set size alone is not decisive; the comparison class and the task's query structure are part of any recommendation.

Design rules, within the stated classes

Four rules, each with the class it holds in

Send a step its dependencies, not the history

Holds for chains where each step reads O(1) earlier blocks (Proposition 3). Except when the whole task fits in one call, where one-call execution is cheaper still.

Reach state by random access

Holds against deterministic, always-correct, non-speculative sequential interfaces on pointer chasing (Theorem 4). The speculative case is open.

Persist reusable blocks

Holds for bit-reversal reuse with C = o(n) (Theorem 6); no model-call gain when the live state fits in context (regime i).

Buy feedback before extra samples when a check is cheap

Holds on the hard family against the stage-local no-feedback class for fixed γ > 0 and fixed cv (Theorems 8 and 9). For growing verifier costs, compare actual costs; equal asymptotic order does not establish an advantage. The reliability scaling is checked in simulation only.

What was checked, and how

Simulators that satisfy the hypotheses by construction, then one real model

Accounting statements (calls, tokens, memory operations) hold for any oracle; reliability statements depend on the oracle's step error and on verifier quality. The two stages test different parts of the theory.

Scope of the evidence. The controlled simulators implement the memory, error and execution rules the theorems assume, so they check the accounting and the algebra; they are not evidence that production agents satisfy those assumptions. The real-model runs exercise the communication accounting only: the oracle made no error in 300 synthetic steps and 320 MATH links of calibration, so the voting and checkpoint conditions were never run with a real model. The reliability theory rests on simulation alone.

Real model as the semantic oracle accounting only

One fixed frontier reasoning model was used, with 30 chains per cell and no temperature override; the synthetic-chain experiment used its lowest supported reasoning effort. Traffic-prediction parameters were extrapolated from the smallest tested instances, with nothing fitted to larger measurements. The final runs nevertheless include a routing correction made after inspecting test outputs, as disclosed in the paper. The synthetic task is an 8-digit state rotated, digit-shifted and partially reversed each step, so every transition has computable ground truth. Chained MATH-500 follows Compositional GSM: problem i+1 has one integer literal replaced by (Xi + c); the substituted literal has its original value when Xi is correct, so the gold answer is then preserved, and an incorrect Xi changes the next problem. Where the sixteen problems fit in one call, the Direct condition is cheapest of all and answers the final link correctly in all 30 chains; that is a finite-size observation, not a test of regime (i). The controller's parsing and normalisation are uncharged classical work, so these runs test the accounting of an implemented harness, not the provenance-dependent lower bounds.

What the paper does not settle

Speculative sequential access

Whether Ω(kn) survives arbitrary prefetching, preprocessing and a bounded cache is open. Yao's lemma does not restore the visit-order inequality, and a one-time scan cannot be charged once per hop. The separation is claimed only for the non-speculative class.

The one-stack constant

With opaque blocks, correctness on every input and no hidden content-dependent state (h = 0), the buffered one-stack bounds leave a gap between n/3 necessary context blocks and ⌈(n+1)/2⌉ sufficient blocks. Only the linear order is claimed. Two stacks are a different architecture.

Unrestricted reliability strategies

The sampling lower bound is against the stage-local no-feedback class; the checkpoint optimum is within the rollback class. Correlated errors are covered only by a conditional-hazard envelope, and a marginal error rate alone implies neither amplification nor the checkpoint formula.
